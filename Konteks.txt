 > Step 2: Buka Terminal di Folder Project
   Setelah di-extract, buka terminal/command prompt di dalam folder project tersebut.

   Cara cepat di Windows:

   Buka folder project di File Explorer
   Klik address bar di atas, ketik cmd, tekan Enter
   Step 3: Edit File .env
   Buka file .env dengan Notepad atau editor apapun, ubah:

   text

   DATABASE_URL="file:/home/z/my-project/db/custom.db"
   Menjadi:

   text

   DATABASE_URL="file:./db/custom.db"
   Ini karena di server path-nya absolute (/home/z/my-project/...), tapi di laptop kamu perlu relative path.

   Step 4: Install Dependencies & Setup
   bash

   npm install
   npx prisma generate
   npx prisma db push
   npm install akan menginstall semua library (butuh koneksi internet, sekitar 1-2 menit)
   prisma db push akan membuat file database db/custom.db secara otomatis

   ini adalah step dari z.ai, file yang kamu lihat adalah hasil project yang saya minta oleh z.ai
   saya ingin merunning lokal, tolong ikuti stepnya dari z.ai
